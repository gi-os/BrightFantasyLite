Fill this in, then scan the code with the app. Everything happens in this page — the cookies are never sent anywhere, and this file has no network code in it at all.

Where the values come from

  1. Sign in at fantasy.espn.com and open your league.
  2. The league id is in the address bar, after leagueId=.
  3. Open developer tools → Application (or Storage) → Cookies → espn.com.
  4. Copy SWID and espn_s2. Paste them below exactly as shown, braces and all.

A public league needs only the league id. The cookies are what let ESPN show a private one, and they expire every few months — when the app says the login was refused, come back here and make a fresh code.
